# CyberFun Budapest – Waiting List

Static English landing page prototype.

## Preview
Open `index.html` in a browser. No build step or dependencies are required. Archivo loads from Google Fonts when online.

## GitHub Pages
1. Create a repository and upload all files and the `assets/` folder at its root.
2. Open Settings → Pages → Build and deployment.
3. Select Deploy from a branch, choose `main` and `/ (root)`, then Save.
4. Open the URL displayed by GitHub Pages.

## Before production
The form is a demo and does not transmit or store data. Connect a secure CRM/backend, implement consent logging and confirmation email, and supply the final privacy policy, giveaway terms and legal notice. Confirm font and visual asset usage rights. No secrets should be committed to the repository.
